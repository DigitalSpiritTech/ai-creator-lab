# Demo script: two minutes

Target length 2:00. Record the screen at 1920 x 1080 with a light theme, browser zoom at 110 percent, notifications off. Use a project that already has real outputs (the first complete ad from October 26, or a fresh run) so nothing waits on screen; where generation takes time, cut to the finished result. Everything shown is SFW and uses the invented creator Avery Lane and the invented Ridgeline 32 oz insulated bottle. Hide the API keys: show the Settings page with the fields filled and masked, never with a key visible.

Voice: plain, first person, no hype. Read the words in quotes.

| Time | On screen | Action | Say |
| --- | --- | --- | --- |
| 0:00 | Title card, then the Projects page | Hold the card for two seconds, cut to Projects with one project listed. | "This is AI Creator Lab. You tell it what you're selling, and it helps you make a finished vertical ad with a consistent AI creator, on your own Comfy account." |
| 0:10 | Settings | Click Settings. Point at the two masked key fields and the status text. Click the allowance field, type the amount, press Save. Leave Auto-approve unchecked. | "Connect your Comfy and Anthropic keys. They stay on your machine. Set an allowance and nothing can spend past it." |

| 1:20 | Shots tab | Show the board with one approved still per beat: kitchen counter, car interior, gym bench. Click one still to enlarge it, then back. | "Each beat gets a start frame composed from the sheet, the product, and the setting. I approve one per beat." |

| 1:50 | Export tab | Click Export 1080 x 1920. Cut to the finished MP4 playing, captions visible, sound up for about six seconds. | "The app joins the clips in script order with the on-screen text burned in. That's the finished ad." |
| 1:58 | Repository page on screen | Cut to the repository page with the README and the LICENSE file visible in the file list. Hold two seconds. | "It's open source under MIT. The link is below." |

## Before recording

1. Run a full ad ahead of time so every candidate, clip, and the export exist. The first complete run on October 26, 2026 cost about 60 credits.
2. Check the export has 1080 x 1920 and audible speech. Check no key, email address, or private path appears in any frame, including the address bar and the data folder path in Settings.
3. Record at normal speed. Do not speed up generation to pretend it is instant; cut to the result instead and say nothing about timing.
4. Say once, in the voice-over or on a caption, that the example creator and product are invented.
5. Keep the repository link in the video description and in the pinned comment.
