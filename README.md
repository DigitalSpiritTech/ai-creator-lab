# AI Creator Lab

An open-source studio for creators who make short vertical content around a single product, running on your own Comfy account (Comfy Cloud, Comfy API, or Comfy Router). A built-in assistant walks you from "here is what I'm selling" to a locked AI creator character, a script, the shots, and a finished 1080 x 1920 ad.

Status: Phase 0, planning. The product description is in `docs/PRODUCT.md`, the build plan in `docs/PLAN.md`, and the task board in `docs/TASKS.md`. The creator-facing README replaces this file once the first release candidate exists.
